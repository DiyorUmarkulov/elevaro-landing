# Elevaro pleasant light-color concepts

Static site mirror of [elevarosolutions.com](https://elevarosolutions.com/).

- `index.html` — home page (project root)
- `src/` — all other pages and assets

Open http://127.0.0.1:5501/index.html after running:

```bash
python3 -m http.server 5501 --bind 127.0.0.1
```

Serve from the project root (not `src/`).

**Main sections**
- Home, pricing, solutions, industries, results, resources, FAQ, about, contact
- Partners, restaurant funding, free audit, reputation protection, how it works
- 8 service pages, 7 industry playbooks, 15 resource guides

Shared assets: `src/assets/` (`site.css`, `site.js`). Page list: `pages.json`.

---

Three additional static website directions:

1. `version-a-garden` — warm editorial design using ivory, sage, peach, and butter.
2. `version-b-sky` — clean modular design using white, pale blue, aqua, and soft yellow.
3. `version-c-orchard` — friendly rounded design using cream, lavender, mint, peach, and rose.

Each version includes:

- $199, $499, $999, and custom pricing
- selected live restaurant projects
- SEO content previews
- responsive layouts
- working package-selection buttons
- FormSubmit project inquiry form

Open any version's `index.html` directly in a browser. Send one test form after
uploading and confirm the activation email sent by FormSubmit.
